# Useless Projects starter

This fork currently contains a TinkerHub Useless Projects submission template and a blank `index.html`. No application has been implemented in the checked-in default branch.

## Repository status

- `index.html` contains only whitespace; a browser preview is expected to be blank.
- The original submission template is preserved in `SUBMISSION_TEMPLATE.md` for team details, screenshots, demo links, and credits.
- There are no dependencies, environment variables, build commands, or tests yet.

## Start a project

Implement the page in `index.html`, then preview it locally:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Visit http://localhost:8000. Fill in the submission template using actual team information and working artifact links once the project exists. Document the chosen stack and setup commands when adding dependencies.
